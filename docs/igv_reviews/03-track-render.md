# 03 — The Track Abstraction and Rendering Model (IGV 3.0.0-beta.4)

TL;DR: IGV separates _what a track is_ (`org.igv.track.Track`, a state container with identity, visibility, colors, scale, and a `render(RenderContext)` entry point) from _how it draws_ (`org.igv.renderer.Renderer` implementations, stateless-ish objects parameterized by the track). Everything visual about a track (height, color, display mode, data range, autoscale) lives on the track; renderers read it. `org.igv.track.TrackProperties` is the UCSC-track-line–compatible config blob that funnels external configuration (track lines, file headers, session JSON) into those state fields.

## 1. `org.igv.track.Track` — the interface

Core contract (all render-time and state methods; Swing types noted where they leak in):

| Method                                                                                                                                                       | Purpose                                                                                                                                                 |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- |

| `getType()` → `TrackType`                                                                                                                                    | igv.js-compatible track type string (`annotation`, `alignment`, `wig`, ...) used for session export.                                                    |
| `getOrder()` / `setOrder(long)`                                                                                                                              | Ascending sort key among sibling tracks. `long` for igv.js `MAX_SAFE_INTEGER` compatibility. Default 0.                                                 |

The single rendering entry point.                                                           |
| `renderName(Graphics2D, Rectangle, Rectangle)` / `renderAttributes(...)`                                                                                     | Draw the label panel and the sample-attribute color columns (left panels).                                                                              |
| `load(ReferenceFrame)` / `isReadyToPaint(frame)`                                                                                                             | Lazy data prefetch for the visible frame before paint.                                                                                                  |
| `setVisible/isVisible`                                                                                                                                       | Hidden tracks are skipped in layout (`getHeight()` returns 0 when hidden in `AbstractTrack`).                                                           |

### `org.igv.track.AbstractTrack` — defaults and state

Key fields (all private/protected; this is the de-facto track state record):

| Field                                                                     | Default                                                                                            | Meaning                                                                                                                                                                                                                            |
| ------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`, `name`, `sampleId`                                                  | —                                                                                                  | Identity; `getSample()` falls back to name or `AttributeManager.getSampleFor(name)`.                                                                                                                                               |
| `resourceLocator`                                                         | —                                                                                                  | Source file/URL + index + format + track line.                                                                                                                                                                                     |
| `order` (`long`)                                                          | 0 (from `ResourceLocator.getOrder()`)                                                              | Sort order.                                                                                                                                                                                                                        |
| `height`                                                                  | `DEFAULT_HEIGHT = 20`                                                                              | Viewport height; `getHeight()` returns content height if 0, and 0 if invisible.                                                                                                                                                    |
| `minimumHeight`                                                           | 20                                                                                                 | Resize floor.                                                                                                                                                                                                                      |

| `color`, `altColor`, `defaultColor`                                       | null / null / blue (cyan in dark mode)                                                             | `getColor()` falls back to `defaultColor`; `getAltColor()` falls back to `getColor()`.                                                                                                                                             |
| `colorScale` (`ContinuousColorScale`)                                     | null                                                                                               | Heatmap scale; if null, `getColorScale()` derives one: from session per-datatype scale → user prefs → synthesized from `dataRange` + colors (white midpoint if min ≥ 0; white as mid color between negative min and positive max). |

| `useScore`                                                                | false                                                                                              | Score→opacity shading: 9 bins over `[viewLimitMin, viewLimitMax]`, alpha = 0.2 + 0.8·bin/9.                                                                                                                                        |
| `itemRGB`                                                                 | true                                                                                               | BED itemRgb honored.                                                                                                                                                                                                               |
| `visibilityWindow`                                                        | `-1` (`VISIBILITY_WINDOW`)                                                                         | Feature fetch window in bp.                                                                                                                                                                                                        |
| `fontSize`, `showDataRange`, `showFeatureNames`, `drawYLine`, `yLine`     | prefs / true / true / false / 0                                                                    | Cosmetics.                                                                                                                                                                                                                         |
| `dataType` (`DataType`)                                                   | `OTHER`                                                                                            | Drives default renderer selection (see below).                                                                                                                                                                                     |
| `attributes` (`Map<String,String>` upper-cased keys), `autoscaleGroup`    | —                                                                                                  | Track metadata; key `"AUTOSCALE GROUP"` is intercepted into `autoscaleGroup` rather than the attribute map.                                                                                                                        |
| `sampleNames`, `sampleGroups`, `groupBy`, `sampleFilter`, `samplesSorted` | single implied sample = track name                                                                 | Multi-sample tracks (expression, variants, alignments) override via `initSamples`.                                                                                                                                                 |

Notable behaviors:

- **`setProperties(TrackProperties)`** maps external config onto state: min/max/mid → a `DataRange` (mid defaults to `max(min, 0)`); if min & max colors are also given, it synthesizes a `ContinuousColorScale` with `neutralFrom/neutralTo` around the mid (mid color defaults to white); `logScale` → `DataRange.Type.LOG`; `PointsRenderer` in the track line turns off windowing (`WindowFunction.none`); metadata string `Library=x;Sample=y` parsed into attributes (`setMetaData`).
- **Attribute lookup order** in `getAttributeValue`: (1) track's own attribute map (incl. `autoscaleGroup`), (2) `AttributeManager` by `getSample()`, (3) `AttributeManager` by resource path. Keys are case-insensitive via upper-casing.
- **`getFeatureColor(IGVFeature)`** — the color resolution order used by feature renderers: negative strand → `altColor` (only if explicitly set); else explicit track `color`; else `feature.getColor()` (e.g. BED itemRgb parsed into the feature); else data-type special case (CNV "gain"/"loss" → dull red/blue); else `defaultColor`. Then `useScore` applies alpha binning. This is a clean, portable rule.
- **`getDefaultRenderer()`** (used by data tracks): heatmap datatypes (RNAI, COPY_NUMBER, ALLELE_SPECIFIC_COPY_NUMBER, GENE_EXPRESSION, DNA_METHYLATION, LOH, CHIP_CHIP) → `HeatmapRenderer`; everything else → `BarChartRenderer`.

## 3. `org.igv.track.TrackLoader` — format → track dispatch

`TrackLoader.load(ResourceLocator, Genome)` is a giant if/else on `locator.getFormat()` (the extension-derived format string). There is no registry or table — dispatch is hard-coded, ordered:

- Pre-step: format `"bed"` is sniffed from file contents (`FileFormatUtils.determineFormat`) to distinguish bedpe/narrowpeak/etc. `"tbi"` is rejected with a hint to load the `.gz`.
- `htsget` URLs probe the server metadata → VCF → `HtsgetVariantSource` + `VariantTrack`, or BAM/CRAM → alignment loading.
- Representative mappings (format → track class):

| Format(s)                                                                                       | Track / source                                                                                                                                                                                            |
| ----------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `sam, bam, cram, aligned, bedz, *.list`                                                         | `AlignmentTrack` via `AlignmentDataManager` (+ its `CoverageTrack` and `SpliceJunctionTrack` inserted as separate tracks); index required for bam/cram                                                    |
| `vcf` (and htsget VCF)                                                                          | `VariantTrack` over `TribbleFeatureSource`; methylation-rate mode enabled if VCF header has `MR`+`GB` FORMAT fields                                                                                       |
| `wig, bedgraph, bdg, cpg, expr`                                                                 | `WiggleParser` → dataset → `DataSourceTrack` per column                                                                                                                                                   |
| `bw, bigwig, bb, bigbed, biggenepred, bigrepmsk`                                                | `BBFile` reader → `DataSourceTrack`+`BBDataSource` (wig) or `FeatureTrack`/`InteractionTrack`+`BBFeatureSource`                                                                                           |
| `tdf, ibf`                                                                                      | `TDFReader` → `TDFDataSource` → `DataSourceTrack` per column                                                                                                                                              |
| `cn, xcn, snp, igv, loh`                                                                        | `IGVDataset` → `DataSourceTrack` per column (`PointsRenderer` for ALLELE_FREQUENCY)                                                                                                                       |
| `gct`, cufflinks `fpkm_tracking`, `gene_exp.diff`                                               | `ExpressionDataset`/codecs → `DataSourceTrack` (HeatmapRenderer / FPKM scale)                                                                                                                             |
| `seg, cbs, glad, ...`                                                                           | `SegTrack` (+ `CNFreqTrack` "CNV Summary" for multi-sample CN)                                                                                                                                            |
| `gff/gtf` (via tribble codec)                                                                   | `FeatureTrack` wrapped in `GFFFeatureSource` (GFF version-aware)                                                                                                                                          |
| generic tribble (bed, etc.)                                                                     | `FeatureTrack` over `TribbleFeatureSource`; `FeatureFileHeader` track properties/type applied; `.narrowpeak/.broadpeak/.gappedpeak/.regionpeak` → `setUseScore(true)`                                     |
| `bedpe, interact, hic`                                                                          | `InteractionTrack` (`HicSource` for .hic)                                                                                                                                                                 |
| `maf` (mutation), `mut`                                                                         | `SegTrack` over `MutationFeatureSource` (must be tried before MAF alignment format)                                                                                                                       |
| `maf` (alignment), `maf.dict`                                                                   | `MultipleAlignmentTrack`                                                                                                                                                                                  |
| `gistic`, `smap`, `dsi`, `clusters`, `bp/ct/dp/db`, `gwas`, `dranger`, `blast/tabblastn`, `gbk` | dedicated tracks (`GisticTrack`, `FeatureTrack`+`SMAPRenderer`, `DSITrack`, `ClusterTrack`, `BasePairTrack`, `GWASTrack`, `DRangerParser`, `FeatureTrack` of `BlastMapping`, `FeatureTrack` from Genbank) |
| `gmt`, `trio`                                                                                   | Not tracks — gene lists / pedigree loading.                                                                                                                                                               |
| unknown                                                                                         | `FileFormatUtils.determineFormat` retry (recursion), then content sniffing (`CytoBandFileParser.isValid`, `sampleinfo` → `AttributeManager.loadSampleInfo`), else error.                                  |

- After loading, common post-processing applies the `ResourceLocator`'s `trackLine` (parsed to `TrackProperties` → `track.setProperties(tp)`), `featureInfoURL`, `labelField`, `color`, `sampleId`, `autoscaleGroup` to every new track.
- Resource paths vs URLs: no special casing here — `ResourceLocator` unifies local path and URL (`locator.isLocal()`, `FileUtils.isRemote`); index lookup (`isIndexed`) appends `.tbi` for gz paths, `.idx` otherwise, preserving HTTP query strings. Size guards: ~200 MB confirm dialog (÷4 for gz) for non-indexed numeric formats, 10 MB content-sniff limit.

## 4. Grouping, attributes, ordering

- **`org.igv.track.TrackGroup`** — a named, synchronized list of tracks that behaves as a unit for region-score sorting (`getRegionScore` = max over visible tracks) and autoscale (`isAutoScale/setAutoScale`); group height = sum of visible `getContentHeight()`. Groups are used by `TrackPanel` to lay out and sort (e.g. sorting groups by `SampleAttributeComparator` of their tracks).
- **`org.igv.track.AttributeManager`** (singleton, implements `AttributeSupplier`) — the sample/track metadata table:
  - `attributeMap`: row id (sample name or track id/path) → ordered map of upper-cased attribute key → value.
  - `trackSampleMappings`: track id → sample name (from `#samplemapping` section).
  - `attributeNames` (insertion-ordered), per-column `ColumnMetaData` (numeric detection: >1 numeric and <1 non-numeric values; min/max; `isDiverging()` = min < 0; unique counts).
  - Sample-info file format: tab-delimited with optional sections `#sampletable` (header row then rows; col 0 = sample), `#samplemapping` (track → sample), `#colors` (attribute, optional range `min:max` or `*`, then 1 or 2 colors → `MonocolorScale`/`ContinuousColorScale` for numeric columns, discrete `attr_value` → color for symbolic).
  - **Coloring of attribute columns** (`getColor(key, value)`): numeric columns get a synthesized diverging (lightblue-white-blue) or sequential (Blues) scale; symbolic values get colors from `#colors` maps or, failing that, an auto-assigned `ColorPalette` per attribute key.
  - `getGroupableAttributes()` returns attributes with 2–9 unique values (hardcoded non-groupable blacklist like `DATA FILE`, `DATA TYPE`).
  - Special constant `GROUP_AUTOSCALE = "AUTOSCALE GROUP"` — used as an attribute key to link numeric tracks into named autoscale groups.
- **Track ordering/sorting**: tracks carry `order` (long, from load order / `ResourceLocator`); the IGV session and `TrackPanel` reorder lists directly; region-score sorting (`IGV.sortByRegionScore`) sorts by `getRegionScore` over a region; attribute sorting sorts tracks by their sample's attribute values. Track attribute _grouping into panels_ is done by `TrackPanel`/data-type, not by `TrackGroup`.
- **`org.igv.track.TrackSet`** is a minimal named wrapper around a track list (barely used).
- Sample-level grouping _within_ a track: `AbstractTrack.setSampleGroupBy(attribute)` rebuilds `sampleGroups` by bucketing samples on `AttributeManager.getAttribute(sample, key)`, after applying `SampleFilter`.

## 5. `org.igv.renderer.DataRange` — the scale model

Fields: `type` (`Type {LINEAR, LOG}`, default LINEAR), `minimum` (default 0), `baseline` (where y=baseline draws, default 0), `maximum` (required, public field — no default guard), `flipAxis` (invert Y), `drawBaseline` (default true).

Semantics (from `XYPlotRenderer.renderScores`):

- Pixel mapping: `yScaleFactor = rect.height / (max − min)`; baseline's pixel row `baseY = rect.y + (max − baseline)·yScaleFactor`, clamped to the rect. Data point: `pY = baseY − (value − baseline)·yScaleFactor` (log: use `log10(value)` and `log10`-transformed min/max/baseline; values ≤ 0 skipped in log mode).
- Coordinates: data X positions use `score.getStart()/getEnd()` (**0-based start, end-exclusive** for `LocusScore`), converted by `(start − origin)/scale`.
- Autoscale: `AbstractTrack` starts with `autoScale = true`; `DataSourceTrack.initScale` computes min/max over fetched scores and calls `setDataRange`. `DataRange.getFromTracks(Collection<Track>)` merges a group: min of mins, max of maxes, **average** of baselines, AND-ed `drawBaseline`/`isLog`. `autoscaleGroup` attribute + `TrackGroup.isAutoScale` implement group-autoscale in the UI/session layer.
- Serialization: JSON `min/mid/max/logScale/flipAxis/drawBaseline` (marshalled as `mid` = baseline; read from `max` key via `fromJson`); legacy XML attributes `minimum/baseline/maximum/flipAxis/drawBaseline` and pre-V3 session `scale="min,mid,max"`.

## 6. Renderer hierarchy and color decisions

```
org.igv.renderer.Renderer<T extends Feature>   // interface: render(List<T>, RenderContext, Rectangle, Track)
├── FeatureRenderer (abstract, Renderer<IGVFeature>)   // one row at a time; reset(); highlightFeature
│   ├── IGVFeatureRenderer        // default feature drawing (bars/arrows, exon coloring, codon translation)
│   ├── SelectableFeatureRenderer // adds click-selection visuals
│   ├── GeneTrackRenderer, SequenceRenderer, GenotypeRenderer, GisticTrackRenderer,
│   │   CytobandRenderer, SMAPRenderer (in org.igv.feature.bionano), DSIRenderer, SpliceJunctionRenderer,
│   │   ArcRenderer, DynSeqRenderer, LineplotRenderer
├── DataRenderer (abstract, Renderer<LocusScore>)      // renderScores + renderAxis + renderGuides; drawScale()
│   ├── XYPlotRenderer (abstract)  // core pixel math (DataRange, log, posColor/negColor)
│   │   ├── BarChartRenderer       // vertical bars per LocusScore
│   │   └── PointsRenderer         // points
│   ├── HeatmapRenderer            // per-cell fill via track.getColorScale().getColor(logScaleData(score))
│   ├── FeatureDensityRenderer
```

- **`org.igv.track.RenderContext`** carries: the `Graphics2D`, a cache of per-color/per-key derived `Graphics2D` instances (`getGraphic2DForColor`), the `ReferenceFrame` (chr, `getOrigin()` = leftmost **0-based double** position, `getScale()` = px per bp, zoom), `trackRectangle`/`visibleRect`/`clipBounds`, `multiframe` (split-screen insertion view) and `expandedInsertionPosition`/`translateX`. It is Swing-bound only through `Graphics2D` and the host `JComponent`; the coordinate fields are portable.
- **Colors for feature tracks**: `IGVFeatureRenderer` delegates to `AbstractTrack.getFeatureColor(feature)` (resolution order in §1) — strand altColor, track color, feature color (from BED `itemRgb` or codec), type defaults — then applies `useScore` alpha binning. Exon coloring: `alternateExonColor` toggles track color/altColor per exon; gene-expression tracks can color exons via the `GENE_EXPRESSION` color scale keyed on exon `expr` attribute; variant genotypes use fixed HET/HOM colors.
- **Colors for data tracks**: `XYPlotRenderer` uses `track.getColor()` for values ≥ baseline and `track.getAltColor()` below baseline; `HeatmapRenderer` maps `logScaleData(score)` through `track.getColorScale()` (with a no-data background color from the scale). Track-line min/max colors become a `ContinuousColorScale` via `setProperties`.
- **Feature attributes → rendering**: the display-name field is configurable (`Track.getLabelField()`, settable from the resource locator; `gffTags` toggles GFF `ID/Name` usage); feature `score` drives `useScore` shading; feature `color` (itemRgb) overrides track color; `RegionScoreType`/datatype drive region-score sortability (`isRegionScoreType`).
- `FeatureTrack` (org.igv.track) owns both a `Renderer` (default `IGVFeatureRenderer`, or `SpliceJunctionRenderer` for `*junctions.bed`) and a `DataRenderer coverageRenderer` (`BarChartRenderer`) — it renders either packed features or coverage depending on zoom/mode. Rows come from `PackedFeatures.pack(displayMode, groupByStrand)`; in EXPANDED/FULL modes the renderer is called once per row with a row rect (`((FeatureRenderer) renderer).reset()` between rows); COLLAPSED renders all features in one call.

## 7. Visibility, collapse/expand

- **Visibility** is a per-track boolean (`visible`); hidden tracks return height 0 and are excluded from `TrackGroup.getVisibleTracks()` / group `getHeight()` and from region scores. Toggling triggers `IGV.revalidateTrackPanels()`. There is no partial transparency model — visibility is binary.
- **Collapse/expand** is `Track.DisplayMode` on the track, consumed by the data-packing layer (`PackedFeatures`): `COLLAPSED` = all features in one row; `SQUISHED` = fewer, thinner rows (FeatureTrack maps SQUISHED → EXPANDED with reduced row height); `EXPANDED` = one row per feature (by strand if `groupByStrand`); `FULL` = one row per feature including non-overlapping layout details. Row height (`rowHeight`) and content height are recomputed from `getNumRows()`; `minimizeHeight()` shrinks to `getMinimumHeight()` with row height 1 (never grows).
- `visibilityWindow` (bp) is the orthogonal "don't render features when zoomed out beyond N bp" control, persisted as `visibilityWindow` in sessions; `-1` = always render.
- Session persistence records, when non-default: `visible`, `displayMode`, `height`, `rowHeight`, `color`, `altColor`, `colorScale`, `autoscale`, `autoscaleGroup`, `windowFunction`, `dataRange (min/mid/max)`, `showDataRange`, `showFeatureNames`, `fontSize`, `order`, `type`, `id`, `name`, `samples/groupBy/sampleFilter`.

## Mab notes

- **Transferable core**: the `Track` state record (id/name/order/height/rowHeight/visibility/displayMode/color/altColor/dataRange/autoScale/visibilityWindow/attributes) and `DataRange` (min/baseline/max + LINEAR|LOG + flipAxis + drawBaseline) map directly to plain Rust structs; the render interface can be a `render(&self, ctx, rect)` trait where `ctx` carries a viewport (origin, scale, chr) and a generic drawing backend instead of `Graphics2D`.
- **Swing-specific** (do not port): `TrackPanelScrollPane` viewport back-pointer, `MouseEvent`/`TrackClickEvent`, `renderName`/`renderAttributes` Graphics plumbing, tooltip `TooltipTextFrame`, `PropertyChangeSupport`. Keep the _concepts_ (name panel, attribute color columns, click → feature) but express them as UI events, not track methods.
- `TrackProperties` is a good template for Mab's track-line/config layer: keep it a flat, permissive struct with `Option` fields applied onto track state in one well-defined place (`setProperties` analog), including the UCSC fields (`itemRgb`, `useScore`, `viewLimits`, `baseCoord`) — note `baseCoord` exists precisely because UCSC formats mix 0- and 1-based conventions; decide per-format, explicitly.
- Coordinate conventions to preserve: features and `LocusScore` use **0-based start, end-exclusive**; screen positions are fractional doubles; `getRegionScore` regions are 0-based/half-open; only UCSC track-line parsing has to deal with 1-based input.
- Keep color resolution as a documented cascade (strand altColor → track color → feature color → type default → theme default) plus a separate `useScore` alpha binning step and a `ContinuousColorScale` for numeric data; this is cheap to implement and matches user expectations.
- `DataRange.getFromTracks` (min/max merge, mean baseline) is the whole group-autoscale algorithm at data level — trivially portable; pair it with the `autoscaleGroup` string attribute rather than object references.
- The format→track dispatch being a hardcoded if/else is a lesson: in Rust, prefer a table of format descriptors (extension/sniffer → constructor) from day one; IGV's recursion + content sniffing fallback is worth replicating, but as ordered matcher rules.
- `AttributeManager`'s single global table (sample → attributes, track→sample mapping, per-column numeric inference and auto color scales) is powerful but global mutable state; in Rust make it an owned `AttributeTable` passed to layout, with the numeric/diverging inference and palette assignment logic intact.
- WindowFunction (`none…density`) is the tile-reduction contract between data layers and tracks; define it early in Mab's data-source API since datasources must implement all of them per zoom level.
- DisplayMode (COLLAPSED/SQUISHED/EXPANDED/FULL) plus PackedFeatures row packing is a track-layout concern independent of the renderer; consider porting the packing algorithm as a pure function `features → rows`.
